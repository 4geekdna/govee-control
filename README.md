# Govee Control

Mobile-first web dashboard to control your Govee smart lights from your phone.

- Pure client-side (no backend needed)
- Optimized for **iOS Chrome & Safari**
- Runs on GitHub Pages
- Uses the official Govee Developer API

**Live URL:** https://4geekdna.github.io/govee-control/

## Features

- Secure local storage of your Govee API key
- List all your Govee devices
- Large On / Off buttons
- Brightness slider (1–100%)
- Color picker (RGB)
- Color temperature support when available
- **All On** / **All Off** buttons
- Dark theme by default (perfect for lighting control)
- Fully touch-optimized for iPhone

## Deployment (one-time)

1. Go to the repository → **Settings** → **Pages**
2. Under **Build and deployment**, set **Source** to **GitHub Actions**
3. The workflow will automatically deploy on every push to `main`

## How to Use

1. Open https://4geekdna.github.io/govee-control/ on your iPhone
2. Paste your Govee API key
3. Tap **Connect**
4. Control your lights

## Getting a Govee API Key

1. Open the **Govee Home** app
2. Go to your Profile → Settings (gear icon)
3. Tap **Apply for API Key**
4. Fill the form and submit
5. Check your email — the key will arrive shortly

---

Enjoy controlling your lights from anywhere on your network (or over the internet via Govee cloud).
